# DSH Tripo Studio

**在 DSH Desktop 中，把参考图、拆件任务和 Tripo 3D 生成放进同一个工作台。**

当前版本 **0.3.3** · Windows 本地插件 · Tripo 国内站 · MIT

> 仓库名为 `dsh-tripo-blender`，插件实际名称及包名分别是 **DSH Tripo Studio**、`dsh-tripo-studio`。它不是 Blender 插件，也不会自动启动 Blender、修模、装配或绑定骨骼。生成结果可以下载后交给 Blender 等工具继续处理。

## 能做什么

- **参考图创作**：文生图、图像编辑、本地 PNG/JPEG 导入，整理和选择候选图。
- **拆件准备**：AI 生成整张拆件图（结构化、可编辑的通用提示词）、提取部件参考图、裁剪与套索选区。
- **统一建模**：每个部件标为 **主要（绿）**、**次要（蓝）** 或 **基准（红）**。主要与基准部件各自单独图生 3D；勾选的次要部件不单独收费，而是随它们所在的整张拆件图一次建模。所有任务在同一页审阅后提交；格式转换也独立确认。
- **明确的生成方式**：参数区用「文生图／图生图」页签区分，按钮文字写明本次模式。
- **余额与实扣积分**：审批框中可只读查询 Tripo 国内站余额/冻结积分并与参考积分对比；可按官方用量记录回填任务实扣积分。
- **任务与资产管理**：项目草稿、任务状态、按 task_id 查询/关联、失败下载重试、隐藏/恢复及有引用保护的本机删除。
- **3D 预览**：查看已下载的项目模型或导入本机文件，旋转、线框、网格与背景设置，导出展示用 GLB 副本。
- **适应侧栏的界面**：画布优先布局、可折叠资产库、画布下方参数区、底部任务区，以及主题、配色和控件尺寸设置。

“拆件”指参考图片与生成任务的拆分，**不等于自动拆分已有 3D 网格**。本机删除/隐藏记录、暂停跟踪，也**不等于取消云端任务或退费**。

## 工作流程

```text
文字 / 本地参考图
       ↓
生成或编辑候选图 → 人工选择与确认
       ↓
整张拆件图 / 部件提取 / 裁剪 → 标记 主要·次要·基准
       ↓
统一审阅收费任务 → Tripo 图生 3D
       ↓
查询结果 → 下载 → 本地预览
       ↓
按需交给 Blender 等外部工具后处理
```

## 快速开始

### 1. 准备环境

- **Windows + 已安装且已初始化的 DSH Desktop**。本地安装脚本针对其现有 web profile，不是通用网站部署脚本。
- Node.js：包声明最低 `>=20`；新安装建议使用仍受维护的 **Node.js 22 或 24**。
- 若要实际生成：自行准备 **Tripo 国内站** API Key 和足够积分。仅本机导入、预览不需要供应商 Key。

### 2. 安装到 DSH

下载/克隆仓库，在仓库目录打开 PowerShell。正式安装前，先正常退出 DSH：

```powershell
cd .\plugin
node .\scripts\install-local.mjs --dry-run
# 阅读预检结果，确认路径无误且 DSH 已退出，再执行：
node .\scripts\install-local.mjs --apply
```

发布快照已带当前客户端 `plugin/lib/client-v0.3.3.js`，普通安装无需先安装开发依赖。若自行修改源码，则按[开发说明](docs/DEVELOPMENT.md)先重新构建。

安装器会备份旧插件和相关 profile，保留用户数据；不会自动启动/强行结束 DSH，也不会替你执行全局依赖安装。详细说明与卸载方式见[安装与配置](docs/INSTALLATION.md)。

### 3. 首次使用

1. 手动启动 DSH，在侧栏打开 **Tripo Studio**，建立项目。
2. 在连接设置填写**国内站** Key。可仅在本次会话使用；Windows 支持 DPAPI 加密记住。
3. 导入参考图或填写提示词，设置图像/3D 参数。
4. 只有需要生成时才开启收费功能；**检查确认弹窗中的任务和参数后再提交**。
5. 在任务区查询结果、下载并预览；下载失败优先重试下载，不要重复生成。

## 费用、隐私与使用边界

- 当前固定连接 `https://openapi.tripo3d.com/v3`，不自动切换国际站、不提供任意 API 地址配置。旧站任务不会通过国内站自动查询或重交。
- 真实生成会将相应提示词、参考图提交给供应商；请确保有使用和上传这些素材的权利。
- 保存 Key、创建本机项目不等于提交收费任务。收费需要独立启用与逐次确认；收费 POST 不自动重试。界面价格仅供参考，以供应商账户结算为准。
- 模型预览支持 GLB、自包含 glTF、FBX、OBJ、STL；USDZ/3MF 仅下载。外部贴图/资源与复杂材质不保证完整还原。预览导出的 GLB 是展示副本，不应替代原始资产归档。
- 本插件只面向可信本机环境，默认拒绝远程/反代访问。**不能直接作为 GitHub Pages 在线生成服务。**
- 不含自动 Blender 修复、装配、重拓扑、骨骼绑定、动画或布料模拟；也未实现 WebUI、NAI 或本地生成模型后端。
- 此仓库只发布代码和必要测试夹具，**不附带角色模型、贴图、个人参考图、项目记录或 API Key**。
