## 2. 源码与安全边界复核

| 检查点 | 结果与边界 |
|---|---|
| 本机访问 | 路由检查 loopback/Host，拒绝代理头，检查同源/Fetch-Site、请求标记与写操作 CSRF；不支持公开反代部署 |
| Key 管理 | 本机后端、会话模式或 Windows DPAPI CurrentUser；无明文持久化回退；状态不回传 Key；清除标记防止意外回退环境凭据 |
| 收费审批 | 任务参数、站点、账户与输入内容绑定审批；独立收费开关；收费 POST 不自动重试，未知结果不自动再生成 |
| 任务隔离 | 项目/账户/站点及 task_id 校验；恢复和查询不重发收费；删除/隐藏保留依赖保护，不冒充云端取消 |
| 下载边界 | HTTPS/可信域名、DNS 非公网地址拒绝、解析固定、逐跳重定向检查、大小/超时限制；不给 CDN 携带 API Authorization |
| 存储与安装 | 数据位于插件目录外；索引备份、路径/重叠保护；安装默认 dry-run、明确 apply、检测宿主退出并备份，不关闭完整性检查 |
| 许可 | 原有 MIT 及 Three.js/React/ReactDOM 声明保留；API 服务和生成内容权利另行约束 |

这是重点静态阅读与现有测试覆盖，不是全面渗透测试。模型/图片头部校验不是恶意文件扫描；同一 Windows 账户被控制时 DPAPI 不能提供应用级隔离。

## 5. 凭据、个人数据与 Git 历史

- 对发布白名单文本做启发式秘密检查与人工聚焦复核，未发现需带入发布包的真实 Key、私钥、认证远程 URL、私人 MCP 连接信息或用户绝对路径。测试中的 dummy/mock 值按测试上下文辨认，扫描器不保证发现所有秘密。
- 原仓库只读核对：6 个提交、0 个 remote、1,101 个当前跟踪文件；当前跟踪路径及历史对象路径中，没有匹配所检查模型扩展名的文件。
- 对原历史的 **570 个文本 blob**执行部分高置信秘密模式检查，未命中；另外 **467 个非该范围 blob 未扫描内容**，未递归检查旧归档内部。此结果**不能证明原历史无个人数据/秘密**。
- 因此采用全新文件快照，不复制原 `.git`、旧文档日志/截图、归档、原型与安装配置。原 Git 历史不属于本次发布材料，也不建议直接拿原工作区执行公开 push。
- 加入模型、图片、运行数据、秘密、依赖及归档忽略规则，并对唯一测试 PNG 显式豁免；最终是否带入由严格白名单和包内校验共同决定，不靠 `.gitignore` 单独保证。

## 6. 保留事项与建议

1. **公开前由仓库所有者最终确认**源代码/第三方许可及项目命名，不暗示官方背书。生成内容不因代码使用 MIT 就自动获得同等许可。
2. 使用者安装后自行验收当前 DSH 版本。不要因为模拟测试通过就宣称所有宿主版本、真实 API 或模型格式完全兼容。
3. 固定国内站接口、模型目录、价格和退役日期可能变化；源码资料核对日期为 2026-09-22，运行前关注供应商公告。
4. 先建私有 GitHub 仓库、检查文件与安全设置，再决定公开；任何后续代码/依赖改动都需重新审计与打包。
5. 不为改善上传体验而移除审批、本机访问限制或 `private: true`；后者只防 npm 误发布，不影响 GitHub。
