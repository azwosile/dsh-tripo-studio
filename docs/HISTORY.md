# 历史记录整理说明

本次发布把文档分成三种职责：

| 位置 | 职责 |
|---|---|
| 根目录 `README.md` | 当前功能、使用入口与明确限制 |
| `CHANGELOG.md` | 0.1.0 至 0.3.5 的产品演进，以及本次发布整理 |

本次以独立文件快照发布，不复制原 `.git`，没有创建新提交/标签，也没有上传 GitHub。需要保留私有开发溯源时，请另行安全备份原工作区，而不是把它与公开源码一起上传。
