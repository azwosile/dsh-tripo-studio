# dsh-tripo-studio 0.2.3

## 新增：界面填写 Tripo API 密钥

打开 DSH 内 **Tripo Studio → 创作工作流 → 连接设置**，在「Tripo API 密钥」输入框粘贴密钥，选择是否加密保存，以及是否启用收费生成，然后点击「保存连接设置」。立即生效，不需要重启。可点击「查询余额（不提交生成）」检查凭据是否可用。

- 默认密码框；可临时显示，保存尝试后清空输入。服务器不回传原文，也不显示尾号。
- Windows 加密保存使用当前用户 DPAPI；位置为项目数据目录中的 `secrets/connection.json`（默认 `%APPDATA%/dsh-desktop/tripo-studio/secrets/connection.json`），不是插件安装目录或项目 state.json。不采用明文回退。
- 不勾选加密保存时仅当前后端运行有效；重启恢复已有加密配置或环境变量。
- 配置优先级：保存的设置优先于环境变量。损坏 / 无法解密时停止使用，不悄悄回退。
- 「清除密钥」须再次确认，清空当前凭据、关闭收费，并以不含密钥的禁用标记阻止环境变量在重启后重新启用；不取消云端任务，也不保证退款。
- 本机同源 + CSRF 校验；忙碌的提交 / 查询 / 下载期间拒绝修改凭据。更换账户后旧草稿审批和历史任务的账户检查仍有效。
- 保存 / 清除不请求供应商，余额查询由用户明确点击；生成仍逐笔审批。不要把真实密钥发给聊天代理。
- DPAPI 不是防御同一 Windows 用户下恶意程序的保险箱；本功能不用于多用户或公网服务。

## 能力与边界

| 能力 | 实现 |
| --- | --- |
| 文生图 / 图像编辑 | Tripo v3 的 `text-to-image` / `image-to-image` |
| 图像模型 | `chat_image_2.5_flare`、`chat_image_2.5_sunburst`、`chat_image_2` |
| 四图候选 | 四个独立收费任务，明确展示数量，不虚构 `n=4` 参数 |
| 部件提取 | 图像编辑提示词；单件或拆件图，须人工核对 |
| 本地裁剪 | 手动框选、百分比坐标、纯色背景连通区域检测、方图补白 |
| 图生 3D | 独立参考图逐件提交；`v3.1-20260211` / `v3.0-20250812` |
| 审批 | 草稿绑定输入哈希、参数与凭据指纹；未确认不提交 |
| 持久化 | 本地项目、任务 ID、独立资产；重新打开只查询，不重新生成 |
| 输出 | 受控同源资产路由、原始 GLB 下载、预览、项目清单 |

自动裁剪不是语义分割；AI 提取不是精确的原图像素分割。自动 Blender 装配、绑定、动力学、DCC Bridge、Agent 工具、多用户计费和多格式云转换不在本版实现范围内。

## 服务端配置

```text
TRIPO_API_KEY                 仅在后端进程设置，不写入前端或项目文件
TRIPO_STUDIO_ENABLE_PAID=1    明确启用收费提交；缺省关闭
TRIPO_STUDIO_DATA_DIR         可选，本地项目数据目录
TRIPO_ASSET_HOSTS             可选，核实后添加的精确 CDN 主机名，逗号分隔
```

Windows 默认数据目录为 `%APPDATA%\dsh-desktop\tripo-studio`。插件文件与项目数据分开，停用脚本不会删除模型或项目。

环境变量不是系统密钥保险箱，同权限本机程序仍可能读取。当前服务拒绝公网、代理及跨站请求；不要自行放宽校验后用于多人服务。只运行一个使用该数据目录的后端实例；本版没有跨进程写锁或远端 exactly-once 保证。

「停止跟踪」只停止查询，不取消云端任务、不保证退款。提交结果未知时不会自动重发。显式重试下载会重新查询成功任务的输出 URL，但不会重新提交生成；能否更新过期 URL 取决于供应商。

## 安装与测试

完整说明见交付根目录的 `docs/mcp-tripo-install-and-acceptance.md`。

在目标 Windows 主机、源码目录内：

```sh
node scripts/test-host.mjs
node scripts/install-local.mjs --dry-run
# 正常退出 DSH 并确认之后，才执行：
node scripts/install-local.mjs --apply
```

安装器不执行全局 pnpm 安装，不修改其他插件或 lockfile，不取消宿主安全检查。默认不写入。

开发测试（源码目录）：

```sh
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:ui
```

Linux 浏览器测试环境可能需要 `npx playwright install --with-deps chromium`；这是开发依赖，不属于最终用户运行插件的前提。

停用（先关闭 DSH）：

```sh
node scripts/uninstall-local.mjs --dry-run
node scripts/uninstall-local.mjs --apply
```

保留原始模型时，请用任务资产列表的「下载」。预览中的 GLB 导出为规范化展示副本，不承诺保留原始单位、朝向或动画；不会替代原始输出的下载。
